Ok this is my **real** first blog post.

## Nostalgic Web Building
Honestly, it's been a long time since I've built a website. I remember at the start of my coding journey experimenting with HTML, CSS, JS, etc. and I was so proud of myself after making my first site! This was also pre-AI, so it was "handwritten." Ever since then, I've come really far as a coder, and have forgotten a bit of my webdev roots. Building a personal website has always been on my bucket list, and I'm glad I can finally check it off and reminsice about how I started coding.

## Tech Stack
- **Next.js** — used for fast loading and routing
- **React and TypeScript** — making components reusable (yippee)
- **Tailwind CSS** — pretty styling
- **Framer Motion** — for the draggable mini-windows (I love them)
- **Markdown + gray-matter** — for writing blog posts in markdown style instead of long jsons

## Thoughts on Vibecoding
This was also the first time I tried vibecoding a website, and I was honestly astonished by how good and bad AI is. If you're specific about your instructions, it works pretty well and you only have to make a few minor tweaks for some decent code. Yet at the same time, if you give it too much control, it will mess everything up and you sigh disappointedly (but also think ok phew human overview is still needed).

It definitely sped up my work process, and was a good way to learn the balance between human coding and using AI, as I still want to learn new algorithms and techniques (without leaving all that to AI), but now I can learn them faster thanks to the resources at my disposal. 

I really hope I don't end up as a CS student who only knows how to prompt, not code, so I want to be very careful with AI-assisted coding.
