# Personal Website

My personal site — home page, projects, blog, and contact, all built from scratch to learn Next.js and React along the way.

**Live site:** [add your deployed URL here once it's live]

## Tech Stack

- **[Next.js](https://nextjs.org/)** — React framework handling routing, rendering, and fast page loads (App Router)
- **[React](https://react.dev/)** — component-based UI library Next.js is built on
- **[TypeScript](https://www.typescriptlang.org/)** — adds type safety on top of JavaScript
- **[Tailwind CSS](https://tailwindcss.com/)** — utility-first styling
- **[Framer Motion](https://www.framer.com/motion/)** — powers the draggable mini-windows on the homepage
- **[gray-matter](https://github.com/jonschlinkert/gray-matter)** + **[react-markdown](https://github.com/remarkjs/react-markdown)** — parse and render blog posts written in Markdown
- **[lucide-react](https://lucide.dev/)** + **[react-icons](https://react-icons.github.io/react-icons/)** — icons used in the footer and contact links

## Project Structure

```
app/
  page.tsx            → Home page
  projects/           → Projects page
  blog/
    page.tsx           → Blog list (with pagination)
    [slug]/page.tsx     → Individual blog post pages
  contact/            → Contact page
  layout.tsx          → Shared layout (Navbar, Footer, fonts)

components/           → Reusable components (Navbar, Footer, ProjectCard, MiniWindow, etc.)
data/                 → Project data (projects.ts) and blog post Markdown files (data/posts/)
lib/                  → Helper functions (posts.ts reads and parses Markdown files)
public/                → Static assets (images, resume PDF)
```

## Running Locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Adding a New Blog Post

Add a new `.md` file to `data/posts/`, with frontmatter at the top:

```md
---
title: "Post Title"
date: "YYYY-MM-DD"
summary: "One-sentence teaser shown on the blog list page."
tags: ["devlog"]
---

Post content goes here, written in regular Markdown.
```

The post will automatically show up on `/blog`, sorted newest first.

## Adding a New Project

Add a new entry to the `projects` array in `data/projects.ts`:

```ts
{
  title: "Project Name",
  summary: "Short description.",
  image: "/projects/your-image.jpg",
  repoUrl: "https://github.com/yourusername/your-repo",
}
```
