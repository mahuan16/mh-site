## Tech Stack

- **[Next.js](https://nextjs.org/)** — React framework handling routing, rendering, and fast page loads (App Router)
- **[React](https://react.dev/)** — component-based UI library Next.js is built on
- **[TypeScript](https://www.typescriptlang.org/)** — adds type safety on top of JavaScript
- **[Tailwind CSS](https://tailwindcss.com/)** — utility-first styling
- **[Framer Motion](https://www.framer.com/motion/)** — powers the draggable mini-windows on the homepage
- **[gray-matter](https://github.com/jonschlinkert/gray-matter)** + **[react-markdown](https://github.com/remarkjs/react-markdown)** — parse and render blog posts written in Markdown
- **[lucide-react](https://lucide.dev/)** + **[react-icons](https://react-icons.github.io/react-icons/)** — icons used in the footer and contact links
